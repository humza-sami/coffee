# Coffee v0.1.0-beta.1 — Beta 1

This release updates the project presentation and starts numbered beta releases on the path to v1.0.
It does not add runtime features or implement a unified VM.

- Reorganised README with a shared-machine example, terminology, commands and roadmap.
- Added a test-server support form and a getting-started guide.
- Changed the executable and package version to `0.1.0-beta.1`.

The task runner still uses one coordinator and Bean workers. Each task must fit one Bean; pooled memory, pooled storage,
transparent distributed threads and coordinator failover are not implemented. Use encrypted tunnels or networks for remote
connections. See [limitations](../limitations.md) and [security](../../SECURITY.md).

Earlier release notes and protocol identifiers remain unchanged. The current API identifier is still `coffee/v1alpha1`;
numbered beta branding does not change the wire format.
