# Coffee artwork

## Terminal illustration

`coffee-terminal.gif` is a code-rendered retro pixel animation created for Coffee. `coffee-terminal.png` is its static
companion. The lettering, machine icons, grid and connecting wires are original programmatic graphics, not a runtime
screenshot. The animation loops in 2.8 seconds at 25 frames per second.

The three machines and their hardware specs illustrate the long-term goal of one unified VM. The numbers are examples,
not measured hardware or resources currently pooled by Coffee. The current beta runs tasks on individual Beans.

Supporting text was rendered with DejaVu Sans Mono. These assets contain rendered pixels; no font file is distributed
with them.

## Earlier artwork

`coffee-banner-v1.png` and `coffee-mark-v1.png` are generated artwork created for Coffee on 22 November 2026. No external
brand artwork was supplied. They depict cooperating compute nodes. These earlier assets remain available, but the README
uses the terminal illustration above.

Artwork communicates the vision; it is not evidence of pooled memory, a larger virtual machine or multi-device performance.
